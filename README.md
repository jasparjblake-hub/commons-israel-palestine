# The Commons on Israel and Palestine

A searchable record of what MPs said in the House of Commons about Israel and Palestine between October 2023 and September 2026, with the words behind every entry and data on the seats they represent.

The site is plain HTML, CSS and JavaScript with no server. Open `index.html` through any web server to run it locally.

- `assets/`: the site's code and styles
- `data/`: the data the pages read
- `downloads/`: the same data as CSV files

How the data was collected, coded and checked is set out on the site's Method page.
